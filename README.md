# Digital Clock ⏰

A simple Digital Clock project built using **HTML, CSS, and JavaScript** to practice my frontend web development skills.

## 📌 About the Project

This project displays the current time in a digital clock format. I created it to apply my knowledge of HTML, CSS, and JavaScript by building a small project instead of only following tutorials.

## 🛠️ Technologies Used

- **HTML5** — To create the structure of the clock.
- **CSS3** — To style the clock and design its layout.
- **JavaScript** — To handle the clock's functionality and update the displayed time.

## 📚 What I Learned

While building this project, I practiced:

- Structuring a webpage using HTML.
- Styling and positioning elements with CSS.
- Selecting and manipulating HTML elements using JavaScript.
- Working with JavaScript's date and time functionality.
- Updating webpage content dynamically.
- Connecting HTML, CSS, and JavaScript in a complete project.

## 🚀 How to Run the Project

1. Clone this repository:

   ```bash
   https://github.com/Rahul-Chaurasiya-Code/Digital-Clock
   ```

2. Open the project folder in VS Code.
3. Open `index.html` in your browser to view the Digital Clock.
